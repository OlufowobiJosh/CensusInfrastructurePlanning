# Public Data Dictionary

- **population_by_age_gender.csv:** `age_group` (five-year age band), `gender` (reported gender), `population` (number of records).
- **employment_category_summary.csv:** `category` (broad occupation-derived category), `population` (record count).
- **marital_status_summary.csv:** `status` (reported status or not recorded), `population` (record count).
- **illustrative_population_scenarios.csv:** `years_ahead` (0, 5, 10, 15, 20), `scenario` (hypothetical annual rate), `projected_population` (rounded scenario value).

Source is a single census snapshot; all public outputs are aggregates.
